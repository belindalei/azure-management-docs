# Agentic chat in Microsoft Copilot in Azure

Agentic chat in Microsoft Copilot in Azure lets you describe what you want to accomplish in natural language. Copilot then works through the steps needed to help you get there.

> [!NOTE]
> This article is a draft. Update it with details about the feature's behavior, availability, and limitations before publishing.

## Get started

1. Sign in to the [Azure portal](https://portal.azure.com).
1. Select **Copilot** from the top menu bar.
1. Enter a prompt that describes your goal.

For help phrasing requests, see [Write effective prompts](write-effective-prompts.md).
